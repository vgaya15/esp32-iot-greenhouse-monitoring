# ESP32 IoT Greenhouse Monitoring System

## Project Overview
This project monitors greenhouse environmental conditions using ESP32 and a DHT22 temperature and humidity sensor.

## Hardware Components
- ESP32-C6
- DHT22 Sensor
- LED
- Resistor
- Breadboard and jumper wires

## Technologies Used
- Embedded C / Arduino
- ESP32
- MQTT
- Node-RED
- InfluxDB
- Grafana

## Features
- Real-time temperature and humidity monitoring
- Wi-Fi-based data transmission
- MQTT communication
- Dashboard visualization using Grafana
